# 上海岛 · 当前规则与功能基线

更新：2026-10-09，Task 1。以当前本地实现为准，历史说明仅作设计参考。此文档不表示已完成线上发布或市场验证。

## 产品边界

面向本地青年，上海为样本城市；电脑横屏、城市探索与轻社交，展示 AI 辅助产品设计及开发能力。地图中的岛屿是主题分区，不是行政地图；游戏到达不等于现实到访。

## 当前能力

| 模块 | 已实现 | 演示／限制 |
| --- | --- | --- |
| 身份与存档 | 昵称、头像、出生岛与本机恢复 | 没有真实账户、认证或跨设备同步；同浏览器存档不是多账号隔离 |
| 城市 | 五岛 SVG 总览、一个 3D 样本街区、移动／碰撞／平移／缩放 | 并非五套 3D 城市；实体捏合仍待手动验收 |
| 探索 | 13 个地点可通过五岛地图探索；其中 4 个映射至 3D 街道 | 街道坐标不是地理坐标；距离与热度为示例 |
| 交通 | 4 个地点的方案比较、确认到达、安全落点检查 | 固定示例起点、时间、费用；没有实时路线或支付 |
| 任务 | 5 个探索任务、3 个进阶挑战、5 个徽章；手动领奖 | 当前全部为累计一次性目标；不自动按日或周重置 |
| 广场 | 本机发帖、点赞、想去收藏、按岛筛选、精选示例 | 无真实关注、定位附近或帖子评论；发布和点赞不加经验 |
| 地点轻社交 | 4 个地点留言、学校自选及同校筛选 | 最近 200 条本机留言、5 所学校选项；未经学校认证；示例人物虚构 |
| 小屋 | 3D 房间、回家往返、升级、足迹／地点图鉴／已领取徽章 | 家具槽位随级别增加；家具商店和拖拽装修尚未实现 |
| 部署 | Next.js 静态导出、本地预览与部署包 | 本轮没有发布到 GitHub Pages；历史材料中的公网地址不证明线上版本已更新 |

## 统一计分规则

- 初始金币 100。首次探索每个地点按地点表发经验、金币；重复探索只发 floor(首次经验 × 0.2)，不发金币，不增加不同地点任务。
- 任务进度依据有效、去重的 exploredLocations 推导；领取任务奖励之后，徽章才进入小屋奖杯架。只移动到岛中心不算探索。
- 发布动态、点赞和地点留言均不奖励经验或金币。保留重复探索经验是当前规则，并非防刷完成的经济系统。
- exploredLocations 是累计游戏足迹，不是 GPS 验证到访。小屋地点图鉴与广场的“想去”收藏是两种数据。
- 历史 daily/weekly 字段与包含数字的任务 ID 为兼容旧存档保留，不代表当前刷新周期或目标数量；以 targetCount 为准。
- 旧已领取任务保留，不重复补发奖励；未领取任务按现有足迹重新判断。已有小屋等级、余额不清零；本次费用下降不追溯退款。

## 历史差异与取舍

1. 咖啡目标 3／10 改为 2；美食目标 3／5／10 改为 1，与实际资源量一致，不为凑数虚构地点。
2. 城市冒险家采用当前代码的 10 个地点；历史 15 个目标不采用。公园挑战采用当前 2 个公园。
3. 历史 200／500／1000 小屋费用改为 100／200／300，使一次性展示内容可支撑完整升级。
4. 保留当前代码中的五级头衔；合并旧 mock 与运行时重复等级表。
5. “关注”改为“精选示例”，“附近”改为“按岛筛选”；帖子评论明确待开放；示例热度、距离和动态分别标注。
6. 自动每日／每周重置、发布／获赞经验、真实关注与评论不列为已实现。预留数据库不等于已接入后端。
