# 回家流程（已实现）

1. 城市顶部独立入口或底部点击「回家」，进入个人小屋，加载失败可重试。
2. 沿用城市黄衣蓝帽小人，从剖面前侧进入右侧空通道，约一秒后显示到家提示。
3. 「客厅歇一歇」：沿右侧通道走到客厅空地停留；不模拟坐下，不发放金币或体力。
4. 「看看窗外」：沿右侧通道走到阳台门内侧，面向蓝天绿树；不穿过阳台背景板。
5. 「整理探索成果」滚动至已有足迹、图鉴和徽章区，读取原有存档。
6. 「返回城市」回到城市并跳过五岛开场；同一标签页恢复离开前的位置、平移中心、缩放与角色朝向；无效或不安全位置回退至出生点。刷新恢复会话，不重新播放开场；首次访问保留开场。

行走期间暂停目的地按钮，防止重复指令；离开页面清理动画。系统减少动态效果开启时直接到达。完成行走后按需渲染。

室内为固定路线的角色展示，没有新增自由移动、碰撞系统、奖励或家具摆放功能。保留原窗户与阳台结构，两个开口共用本地 Blender 渲染的简洁蓝天、白云与绿树背景。
