# 必要收尾验收 · 2026-11-06

## 本轮实现
城市独立回家入口，交通/留言顶层弹窗内提供入口；底部当前小屋标为「我的小屋」。小屋顶部固定返回城市，导航立即反馈且重复点击锁定；12秒仍未跳转会允许重试。模型20秒超时、失败重试及返回。城市加载就绪后再选择首访开场或恢复，不闪现五岛开场。

会话状态仅含安全位置、朝向、镜头中心、缩放和全城状态；使用sessionStorage并提供内存降级。恢复不调用探索或奖励函数。碰撞/边界不允许的位置回退出生点。交通到达后立即回家也保存新落点。原玩家存档结构未改。
